Ejercicio 3: if

¿Cuándo se ejecuta este código?

if(edad >= 18){
System.out.println("Mayor");
}
Ver respuesta

Se ejecuta cuando la condición es verdadera.

Ejercicio 4: for

¿Cuántas veces se repite?

for(int i = 1; i <= 5; i++){
System.out.println("Hola");
}
Ver respuesta

Se repite 5 veces.

Ejercicio 5: while

¿Qué hace este código?

int i = 1;

while(i <= 3){
System.out.println(i);
i++;
}
Ver respuesta

Muestra los números: 1, 2 y 3.
