Variables en Java

Las variables son uno de los conceptos más importantes en programación.

¿Qué es una variable?

Una variable es un espacio que se utiliza en un programa para guardar información. Esa información puede ser un número, una palabra o algún dato que el programa necesita utilizar. A cada variable se le asigna un nombre para poder identificarla y utilizarla cuando sea necesario. Se le llama variable porque el valor que guarda puede cambiar mientras el programa se está ejecutando. Las variables son importantes en programación porque permiten almacenar y organizar la información que el programa utiliza para funcionar.

Por ejemplo, una variable puede guardar un número, una palabra o un valor verdadero o falso.

A continuacion podemos observar un ejemplo de una variable escrita de forma correcta.

Tipos de datos básicos

En Java existen diferentes tipos de datos que indican qué tipo de información se puede guardar en una variable. Algunos tipos permiten guardar números, mientras que otros guardan texto o valores como verdadero o falso. Elegir el tipo de dato correcto ayuda a que el programa funcione correctamente.
Por ejemplo

  • int → números enteros
  • double → números con decimales
  • char → un solo carácter
  • String → texto o palabras
  • boolean → verdadero o falso

Ejemplo de variables en Java


public class EjemploVariables {

public static void main(String[] args) {

int edad = 20;

String nombre = "Ana";

double altura = 1.65;

}

}

En este ejemplo se crean tres variables: una para guardar la edad, otra para guardar el nombre y otra para guardar la altura.
