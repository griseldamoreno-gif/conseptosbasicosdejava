Glosario

Variable

Es un espacio donde se guarda información dentro de un programa.

Clase

Es un molde o modelo que se utiliza para crear objetos.

Objeto

Es un elemento específico que se crea a partir de una clase.

if

Estructura que permite tomar decisiones en un programa.

for

Ciclo que repite una acción un número determinado de veces.

while

Ciclo que repite una acción mientras se cumpla una condición.

System.out.println

Se utiliza para mostrar información en la pantalla.

Estructura básica de un programa en Java

public class HolaMundo {

public static void main(String[] args) {

System.out.println("Hola Mundo");

}

}

Un programa en Java sigue un orden. Aquí se explica paso a paso:

1. Clase (class)
Aquí comienza el programa. La clase es donde se organiza todo el código. Ejemplo: public class HolaMundo

2. Método principal (main)
Es la parte donde inicia el programa. Todo lo que está dentro se ejecuta. Ejemplo: public static void main(String[] args)

3. Instrucciones
Son las acciones que realiza el programa, como mostrar mensajes. Ejemplo: System.out.println("Hola Mundo");

En algunos programas es necesario importar librerías para usar ciertas funciones. Por ejemplo, para leer datos del usuario se utiliza la librería Scanner.

En resumen: primero se define la clase, después el método main y dentro de él se escriben las instrucciones que el programa va a ejecutar.
